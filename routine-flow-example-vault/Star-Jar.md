# Star jar reward economy dashboard

Routine Flow supports stateful token economies where completing sized tasks accumulates reward points in a dedicated tracker note.
When the accumulated balance in `star-jar-economy/Star-Jar-Tracker.md` reaches 15 stars (`tracker.stars >= 15`), the routine transitions into a 30-minute prize celebration break and resets the star bank on exit.
