# Focus and analytics dashboard

This dashboard pairs Routine Flow timer views with Bases Chartkit charts.
Routine Flow drives focus sessions and writes metrics back to task frontmatter on completion.
Bases Chartkit queries those frontmatter properties in real time to render charts without page reloads.
